# AutoCar brand logo assets

The PNG files in this directory are original trademark artwork mirrored by the
[car-logos-dataset](https://github.com/filippofilip95/car-logos-dataset), which
records the corresponding [Carlogos](https://www.carlogos.org/) asset sources.
They are not AI generated and are not letter-based replacements.

Source manifest:
https://raw.githubusercontent.com/filippofilip95/car-logos-dataset/master/logos/data.json

Original mirrored assets follow:
https://raw.githubusercontent.com/filippofilip95/car-logos-dataset/master/logos/optimized/{slug}.png

Slugs: audi, bmw, ford, honda, hyundai, kia, lexus, mazda, mercedes-benz,
mitsubishi, porsche, toyota, vinfast, volkswagen, volvo.

The application downloads missing PNG files with size/signature checks; subsequent
requests use the local copy. Brand uploads configured in the API take precedence.
The logo colors and aspect ratios are preserved with object-fit: contain and no
recoloring filter. Some source artworks are established historical logo variants;
this does not claim that every file is a manufacturer's latest 2026 identity.

Manufacturer reference pages consulted:
- Toyota: https://brand.toyota.com/guidelines/visual/logos
- Audi: https://www.audi.com/en/images
- BMW: https://www.press.bmwgroup.com/global/article/detail/T0306305EN/introducing-bmw%E2%80%99s-new-brand-design-for-online-and-offline-communication

Brand marks identify the corresponding manufacturers in this educational showroom.
They remain the trademarks of their respective owners and do not imply affiliation.
